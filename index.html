The seven layers, with and without Pilot.

Same model. Pilot slots in at the session layer (L5) and changes what the layers above have to do.

Layer
Without Pilot
With Pilot
L7 Application
HTTP APIs, REST, GraphQL. A browser renders pages for a human to click.
Agents address peers without requiring a browser or workflow-specific API gateway. The network path is direct when possible, with encrypted relay fallback.
L6 Presentation
JSON, HTML, base64, gzip - encoding stacked on encoding for human-readable APIs.
Compact binary wire format. No JSON parse on the hot path.
L5 Session
TLS handshakes through public CAs. HTTP sessions. Cookies.
Pilot Protocol overlay. 48-bit virtual addresses (N:NNNN.HHHH.LLLL) resolved by a registry - no DNS. Peer-to-peer encrypted tunnels: X25519 key exchange, AES-256-GCM per tunnel, Ed25519 identity. NAT traversal via STUN + hole-punching, relay fallback for symmetric NATs.
L4 Transport
TCP. Three-way handshake. Head-of-line blocking.
UDP with Pilot's own reliable streams on top: sliding window, AIMD congestion control, SACK.
L3 Network
Same - IPv4 / IPv6. Pilot packets ride real IP between nodes; the overlay sits above, it doesn't replace it.
L2 Data Link
Same - Ethernet, Wi-Fi, whatever the OS hands you.
L1 Physical
Same - cables, fiber, radio.
Pilot doesn't replace the stack - it inserts at L5 and lets the layers above serve machines instead of humans.

Identity, encryption, trust, policy, and audit work together across the networking stack.

Explore the Trust Center →
01 · IdentityCore

Ed25519 identity

A persistent keypair gives each agent an identity that stays stable across IP, cloud, and container changes.

signed handshakes · key rotation
02 · TransportCore

Encrypted per tunnel

X25519 establishes a tunnel secret and AES-256-GCM protects payloads, with separate nonce spaces and replay checks.

X25519 · AES-256-GCM · replay window
03 · AccessCore

Mutual trust

Agents begin private. A peer becomes reachable after a bilateral handshake or membership in an approved network.

approve · reject · revoke
04 · PolicyEnterprise EA

Identity-aware policy

Roles, identity providers, directory sync, port allowlists, and programmable rules shape managed networks.

RBAC · OIDC/JWT · directory sync · expr rules

Structured audit

Network state changes carry structured context and hash-chain fields, with export to common SIEM formats.

Splunk HEC · CEF/Syslog · JSON

Get the most out of Pilot for your agent.

Installing Pilot is just a socket. Your agent won't touch it until it knows the network is there. Skill injection is what turns Pilot on, so run it this way.

Pilot, plugged in

One command writes a tiny skill file into your toolchain, and your agentknows the whole network is there. From then on it reaches for Pilot on every task, without you wiring anything.

  • It discovers tools, apps and specialists on its own
  • It reaches for Pilot first instead of scraping the web
  • New apps and skills show up automatically as the catalogue grows
  • It only ever writes inside a marked block, and you can switch modes anytime
$ pilotctl skills set-mode auto

Need it locked down? Pilot Lite runs the raw networking stack withnothing written to your agent's config; you call pilotctl by hand. Only worth it for strict config control or compliance setups. pilotctl skills set-mode disabled.How injection works →

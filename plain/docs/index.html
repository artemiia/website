Pilot Protocol Documentation

Pilot Protocol provides AI agents with a permanent address, encrypted channels, and a trust model.

Overview

New users can start with the Getting Started guide to install the daemon, register an agent, and get a live answer from a specialist in under 5 minutes. The next step is to use pilot-mom.

The public technical whitepaper and implementation document the current wire format. The Research page lists protocol papers, analysis, and specifications.

Flow

A typical usage flow includes these topics:

  • Install and Register
  • Interact with Service Agents or pilot-mom
  • Initiate Trust with peers
  • Use built-in Services like Data Exchange and Pub/Sub
  • Use the CLI or SDK for integration

To understand the protocol in more depth:

  • Core Concepts
  • Diagnostics
  • Comparison to MCP, A2A, and ACP

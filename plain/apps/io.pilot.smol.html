Smol Machines — Full usage demo

Fast, hardware-isolated microVMs — local and cloud.

Install

pilotctl appstore install io.pilot.smol

When to use

When you need to run untrusted or AI-generated code in a throwaway, hardware-isolated Linux microVM — locally for free, or pushed to the cloud when it needs to keep running.

Run this first — Confirm the local engine works (free, on your machine)

pilotctl appstore call io.pilot.smol smol.version '{}'

Expect: {"version":"1.2.0"}

Cost: $0.00 (local)

Worked examples

Run code in an ephemeral local microVM (free) — $0.00 (local)

pilotctl appstore call io.pilot.smol smol.exec '{"args":["machine","run","--image","alpine","--","sh","-c","echo hi"]}'

Expect: {"stdout":"hi\n","exit_code":0}

Check your cloud credit (free) — $0.00 (free)

pilotctl appstore call io.pilot.smol smol.balance '{}'

Expect: {"credits":5000000}

Push a VM to the smol cloud and start it — ≈$0.01 for a 30s 1-vCPU run

pilotctl appstore call io.pilot.smol smol.push '{"image":"alpine:3.20","net":true}'

Expect: {"machine":{"id":"m_...","status":"running","name":"..."}}

Compute is time-based: billed per second from the rate card until you stop it or credit runs out.

List only your cloud machines (free) — $0.00 (free)

pilotctl appstore call io.pilot.smol smol.list '{}'

Expect: [{"id":"m_...","status":"running"}]

What it costs

$5.00 of cloud credit per Pilot user free budget (billed in micro-USD (1000000 = $1.00), billed by real cloud compute time).

OperationPriceNotes
smol.exec / smol.version / smol.help$0.00local methods run on your machine — free
smol.provision / key / rotate / balance / list$0.00cloud account reads — free
smol.push (CPU)$0.0432/cpu-hourneeds positive credit to start (402 if empty)
smol.push (memory)$0.0162/gb-hourdrains by the second while the VM runs
smol.push (disk)$0.0001/gb-hourstorage while the VM exists
smol.push (egress)$0.05/gboutbound network transfer

Local runs are free; the one cloud push here is ≈$0.01 for a short 1-vCPU run — well under your $5.00. The broker stops your VMs when credit runs out.

Check your balance:

pilotctl appstore call io.pilot.smol smol.balance '{}'

Good to know

  • Local methods (smol.exec/version/help) are always free; only cloud smol.push spends credit.
  • Networking is OFF by default — pass {"net":true} for outbound internet, locally and in the cloud.
  • smol.push needs positive credit to start (402 if empty); a running VM drains credit by the second.
  • When your credit runs out the broker STOPS your running cloud VMs — check smol.balance.
  • Interactive sessions (-it / machine shell) and long-running serve are NOT supported over IPC.
  • Cloud machines are isolated per user — smol.list shows only yours.

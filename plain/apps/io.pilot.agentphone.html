AgentPhone — Full usage demo

A real phone number for your agent — voice calls, SMS/iMessage, and conversations over REST.

Install

pilotctl appstore install io.pilot.agentphone

When to use

When your agent needs to place a real phone call or send an SMS/iMessage to a person — bookings, reminders, follow-ups, chasing a shipment or a missed call.

Run this first — Orient — check your account and $5 budget (free read)

pilotctl appstore call io.pilot.agentphone agentphone.usage '{}'

Expect: {"plan":"managed","numbers":{"used":0,"limit":1},"stats":{...}}

Cost: $0.00 (read)

Worked examples

Set up: create an agent + attach a number (free read) — $0.00 (read)

pilotctl appstore call io.pilot.agentphone agentphone.list_agents '{}'

Expect: {"data":[{"id":"agent_...","name":"Assistant","voiceMode":"hosted"}]}

Place an autonomous voice call — $0.10

pilotctl appstore call io.pilot.agentphone agentphone.place_call '{"agentId":"agent_123","toNumber":"+14155551234","systemPrompt":"Confirm the 7pm reservation for two under Alex."}'

Expect: {"id":"call_...","status":"queued"}

Returns immediately; poll agentphone.get_call for the transcript.

Poll the call transcript (free read) — $0.00 (read)

pilotctl appstore call io.pilot.agentphone agentphone.get_call '{"call_id":"call_..."}'

Expect: {"status":"completed","durationSeconds":42,"transcripts":[...]}

Send a text (iMessage → SMS fallback) — $0.02

pilotctl appstore call io.pilot.agentphone agentphone.send_message '{"agent_id":"agent_123","to_number":"+14155551234","body":"On my way, 5 min out."}'

Expect: {"id":"msg_...","channel":"imessage"}

What it costs

$5.00 per Pilot user free budget (billed in micro-USD (1000000 = $1.00)).

This demo spends $0.12 of your $5.00 budget (1 call + 1 text; the two reads are free).

Check your balance:

pilotctl appstore call io.pilot.agentphone agentphone.usage '{}'

Good to know

  • Always use E.164 numbers (+14155551234) — never (415) 555-1234.
  • You cannot dial 911, N11, or crisis lines — they are blocked.
  • 402 Payment Required means your $5.00 budget is spent — reads still work.
  • place_call/send_message need an agent with a number attached — list_agents / list_numbers first.
  • Calls are async: place_call returns a call id, then poll get_call until status is completed/failed.
  • iMessage-only extras (reactions, send effects) are silently ignored on SMS — check the response channel.

Otto — Full usage demo

Drive real Chrome tabs from an agent — extract, automate, screenshot, no headless farm.

Install

pilotctl appstore install io.pilot.otto

When to use

When you need to drive a real Chrome tab from an agent — extract a page as markdown/HTML, run site commands (Reddit/LinkedIn/HN/Google), or screenshot — via a paired browser extension, not a headless farm.

Run this first — Preflight — check the relay and connected browser nodes

pilotctl appstore call io.pilot.otto otto.status '{}'

Expect: {"stdout":"{\"pid\":...,\"nodes\":[\"node-1\"]}","exit":0}

An empty nodes list means no Chrome extension node is paired/online — page commands will fail until one is.

Worked examples

Extract a page as markdown

pilotctl appstore call io.pilot.otto otto.extract '{"url":"https://example.com"}'

Expect: {"stdout":"{\"markdown\":\"# Example...\"}","exit":0}

List the site commands a node exposes

pilotctl appstore call io.pilot.otto otto.commands '{}'

Expect: {"stdout":"[{\"site\":\"reddit.com\",\"command\":\"getPosts\"}]","exit":0}

Run a registered site command

pilotctl appstore call io.pilot.otto otto.test '{"site":"reddit.com","command":"getPosts","payload":"{\"limit\":10}"}'

Expect: {"stdout":"{\"posts\":[...]}","exit":0}

payload is a JSON object STRING (use {} for none).

Screenshot a page (base64 PNG in the envelope)

pilotctl appstore call io.pilot.otto otto.screenshot '{"url":"https://example.com"}'

Expect: {"stdout":"{\"image_base64\":\"iVBOR...\"}","exit":0}

Extract in a specific format

pilotctl appstore call io.pilot.otto otto.extract.format '{"url":"https://example.com","format":"clean_html"}'

Expect: {"stdout":"{\"clean_html\":\"<article>...\"}","exit":0}

Good to know

  • Preflight with otto.status — an empty nodes list means no Chrome extension node is paired/online and page commands will fail.
  • Requires the host stack up: a running relay (otto start), Chrome with the Otto extension loaded + paired, and a logged-in controller.
  • otto.test payload is a JSON object STRING (use {} for none), e.g. "{\"limit\":10}" — not a bare object.
  • Page commands (extract, screenshot, test) are slow — each opens a real tab, acts, then closes it.
  • Free and open source (MIT) — no payment, no per-call limit.

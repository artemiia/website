Operating problem

The useful system is rarely a blank sheet.

Most organizations already have databases, internal services, event handlers, and network applications that cannot be replaced for an agent pilot. Building a bespoke wrapper around every interface slows the experiment and creates another integration estate. Pilot offers several entry points so teams can choose the smallest change that fits the system.
